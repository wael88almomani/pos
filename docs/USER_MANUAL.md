# User manual (short)

1. **Login** with username + PIN; open a **shift** with opening cash (device ID is registered automatically).
2. **POS:** Search products, scan barcodes (keyboard wedge), apply discounts if permitted, take payment (cash/card). Optional **auto-print** and **drawer** after sale from hardware settings.
3. **Held invoices:** Suspend and resume from the cart panel.
4. **Purchases / returns / inventory:** Use **بحث** where available to pick products instead of typing IDs.
5. **Expenses:** Attach receipt photos; previews use local secure URLs.
6. **Reports:** Dashboard, profit, inventory value, hourly sales chart.
7. **Roles:** Admins manage role names and permission matrix under **المستخدمون → الأدوار والصلاحيات**.
8. **Backup / restore:** From header shortcuts; restore validates database integrity first.
